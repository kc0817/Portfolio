## What it does

- Natural phenomena arise from first physics principles — rolling emerges from
  friction rather than being implemented directly
- Graph visualisation for energy loss and momentum conservation
- Telemetry interface for inspecting object state
- Parameterised environment variables: gravity, restitution, friction
- Separating Axis Theorem collision detection for irregular polygons

Built as a final project for AP Physics 1 & 2.
