## What it does

- Regex-based tokenizer that parses strings into mathematical components
- Recursive-descent parser that structures those components into an abstract
  syntax tree
- Custom interface elements — buttons, text, text fields, sliding sidebars —
  because CMU CS Academy provides no UI library
- Interactive function visualisation, taking inspiration from Desmos
