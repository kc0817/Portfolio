## What the code does

Robot control code for a full FIRST Tech Challenge season: autonomous routines,
driver-controlled operation, and the subsystem logic underneath both. The
ballistic solver is the part that aims — it works the launch out from the
projectile's physics rather than reading it off a table of hand-tuned distances,
so a shot from a position nobody practised is the same calculation as a shot from
one they did.

The simulation was built alongside it, drawing 3D trajectory and pose data live so
the solver could be checked against expected physics without a field, a robot, or
a match to spend on finding out.
